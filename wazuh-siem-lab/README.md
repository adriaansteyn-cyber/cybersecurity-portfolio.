# Wazuh SIEM Home Lab

## Project Overview

This project involves building a home Security Information and Event Management (SIEM) lab using Wazuh to develop practical skills in security monitoring, endpoint visibility, and Windows security event analysis.

The lab is being built in a controlled environment using Ubuntu on WSL2, Docker, and a Windows 11 endpoint.

## Objectives

- Deploy and configure a Wazuh SIEM environment.
- Connect a Windows endpoint to the Wazuh manager.
- Explore endpoint log collection and security event monitoring.
- Learn how to identify and investigate potentially suspicious activity.
- Document the lab configuration, testing process, and findings.

## Lab Environment

- **SIEM platform:** Wazuh
- **Deployment:** Docker
- **Linux environment:** Ubuntu on WSL2
- **Endpoint:** Windows 11
- **Status:** In progress
